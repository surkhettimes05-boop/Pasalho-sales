# Pasalho Sales Pilot

Independent proof-of-concept for Pasalho field sales. This project is deliberately separate from the main Pasalho OS until the workflow is proven with real sales representatives and retailers.

## What is included

### Sales Rep PWA — `/`
- Phone + PIN login
- Existing retailer search
- Add new retailer
- Retailer owner/contact, phone, area/route, delivery address and map location
- Payment terms
- Product catalog and categories
- Quantity-based pricing
- Cart and order review
- Delivery date and notes
- Backend-authoritative order pricing
- Order history
- Payment/collection recording against unpaid orders
- Optional WhatsApp order handoff
- Installable PWA shell

### Sales Control Dashboard — `/control`
- Admin login
- Overview metrics
- All sales reps and performance
- Create/enable/disable reps
- All retailers
- New / active / inactive retailer classification
- Lifetime sales, outstanding and overdue
- Average retailer payment days
- All orders, paid amount and balance
- Payment history and payment timing
- Product and quantity-price management

## Stack

- Node.js 20+
- Express
- PostgreSQL / Neon
- Render
- Plain HTML/CSS/JavaScript PWA
- JWT authentication
- bcrypt PIN hashing

## Local setup

1. Copy the environment file:

```bash
cp .env.example .env
```

2. Add a Neon PostgreSQL connection string to `DATABASE_URL`.
3. Set a strong `JWT_SECRET`.
4. Set a strong `ADMIN_PASSWORD`.
5. Set the destination WhatsApp number in international format without `+`.
6. Install and start:

```bash
npm install
npm test
npm run check
npm start
```

Open:
- Sales rep PWA: http://localhost:3000/
- Sales control: http://localhost:3000/control
- Health check: http://localhost:3000/health

The database tables are created automatically at startup.

## First use

1. Open `/control` and sign in using `ADMIN_PASSWORD`.
2. Create at least one sales representative with phone + PIN.
3. Add products and optional quantity price slabs.
4. Sales rep signs in at `/`.
5. Rep adds/selects retailer, creates an order and optionally sends it to WhatsApp.
6. Rep records collections against unpaid orders.
7. Control dashboard reads the same Neon data.

## Neon

Create a PostgreSQL database in Neon and copy its pooled connection string into:

```
DATABASE_URL=postgresql://...
```

Use SSL as provided by Neon.

## Render

This repository includes `render.yaml`.

Required Render environment variables:
- `DATABASE_URL`
- `ADMIN_PASSWORD`
- `WHATSAPP_NUMBER`

`JWT_SECRET` is generated by the Render blueprint configuration.

Build command:

```
npm install
```

Start command:

```
npm start
```

Health endpoint:

```
/health
```

## Pilot boundary

This is not the main Pasalho ERP. It intentionally does not integrate inventory, POS, warehouse, accounting or the existing CEO dashboard. Prove the field-sales workflow first, then integrate the successful pieces later.
